# ProductOS 0.3.0-alpha.3

**Date:** 2026-10-05

## Outcome

This increment makes the research freshness policy executable instead of leaving it as prose.

## Delivered

- source records now declare temporal stability and an explicit review interval;
- deterministic audit computes due dates and detects stale or future-dated verification;
- CI rejects overdue source registries;
- optional URL probing checks access without introducing network dependence into CI;
- Research Curator and methodology guidance distinguish access, freshness, and content review.

## Verification

Repository validation passed for 20 schemas and 38 fixtures; all 34 tests and Ruff checks
passed. The knowledge index was rebuilt and checked, with no index changes or deterministic
concept or terminology collisions. The seed suite contains 21 cases (13 English, four Spanish,
four Brazilian Portuguese); inspection did not assign behavioral scores.

All three current sources are fresh as of 2026-10-05. Optional probes reached every registered
URL with HTTP 200. The two stable research publications are due for review on 2028-09-26;
the evolving professional principles page is due on 2026-12-26. Their recorded verification
date remains 2026-09-27 because URL probing does not constitute content review.

Reproduce the source check with:

```bash
python -m scripts.audit_sources --as-of 2026-10-05 --fail-stale --check-links --timeout 5 --json
```

Network results describe this verification run and may differ on a later run. Regression tests
exercise probe fallback and failure handling without network access.

## Schema migration

Source records now require `freshness.temporal_stability` and `freshness.review_interval_days`.
The three canonical records and the valid source fixture were migrated together. Existing
source records outside this repository must add both fields before validation can pass.

## Boundary

Reachability does not establish that content, locators, or claims are unchanged. A curator still
needs to inspect the source during review, and the first knowledge slice remains `in_review`
pending independent editorial verification.
