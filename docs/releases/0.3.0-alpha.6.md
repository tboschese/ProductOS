# ProductOS 0.3.0-alpha.6

**Date:** 2026-10-06

## Outcome

ProductOS has a local runtime preview. A user can open a terminal, record a product decision
with context and evidence, connect an assistant they already use, preserve its original answer,
and record their own decision. Generated answers remain distinct from reviewed decisions and
approved canonical knowledge.

## Delivered

- Optional Textual terminal and noninteractive `productos` commands sharing the same workspace
  and adapter APIs ([usage](../terminal.md), [ADR-0008](../decisions/0008-local-terminal-and-ai-adapters.md)).
- Personal workspace outside the repository, with versioned schemas for decisions, analyses,
  and AI connections; stale-revision checks; a single-writer lock; and SHA-256 integrity checks
  for frozen prompts, instructions, decision snapshots, and answers.
- Three connection modes: manual export/import, installed Codex CLI in a fresh read-only
  context, and a user-configured command receiving stdin and returning final-answer stdout.
- Explicit timeout and cancellation; interrupted invocations become failed records when the
  workspace is reopened rather than appearing completed.
- Optional structured output checked against the existing decision-record schema. Invalid
  output remains an original answer with validation errors.

## Qualification boundary

Offline tests exercise real subprocess transport against fake assistants, failure paths, and
the terminal workflow at 120×40 and 80×24. One real Codex smoke run completed an illustrative
retention analysis in Markdown, verifying runtime transport and provenance only. It is not a
behavioral baseline. The [21-case pilot](../../evals/baselines/seed-pilot-2026-10-05/README.md)
remains uncalibrated, fails its multilingual gate, and does not qualify arbitrary connected models.

## Verification

The offline suite passes 106 tests. Repository validation passes 25 schemas and 48 fixtures.
Lint passes. Model calls remain outside CI.

## Remaining work

Native provider API adapters, streamed answers, multilingual interface chrome, shared
workspaces, and standalone distribution with embedded knowledge are future increments. Human
calibration of the pilot judge, repeated runs, and independent review of the first knowledge
slice remain required before stable release.
