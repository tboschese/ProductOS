# ProductOS 0.3.0-alpha.2

**Date:** 2026-09-27

## Outcome

This increment turns the behavioral-evaluation design into an auditable data contract and
deterministic reporting workflow without manufacturing a baseline.

## Delivered

- eval-run schema recording repository revision, system version, response generator, judge,
  calibration status, repetitions, raw responses, scores, behavior evidence, and citation checks;
- suite-owned provisional gate policy;
- semantic validation for complete coverage, case alignment, exact behavior checks, applicable
  dimensions, executor configuration, timestamps, and citation counts;
- deterministic summaries for hard failures, expected and forbidden behaviors, critical scores,
  citation coverage, and multilingual decision-quality deltas;
- explicit distinction between passing gates and being release-eligible, including content
  approval state;
- judge protocol and regression tests.

## Validation boundary

Tests construct synthetic assessments so they can exercise pass and fail paths. These values are
not observations of Staff PM skill behavior and must not be cited as a ProductOS baseline.

## Remaining gate

Run the seed suite against a frozen skill revision, calibrate independent judges on shared
responses, then record the first real baseline. Until then, the 0.2.0 behavioral exit gate remains
open.
