# ProductOS 0.2.0-alpha.1

**Date:** 2026-09-27

## Outcome

This alpha establishes the first end-to-end reasoning slice: foundational decision contracts, an executable Staff Product Manager skill, and a multilingual seed eval suite.

## Delivered

- Product Reasoning Engine v0;
- evidence, uncertainty, risk, and decision models;
- five runtime schemas and a decision-record contract;
- Staff Product Manager skill with progressive disclosure;
- twelve English decision families;
- Portuguese and Spanish variants for four core families;
- seed regression manifest and unscored packet export;
- repository checks for case references and multilingual family integrity.

## Validation

- all repository schemas and positive/negative fixtures pass;
- repository unit tests pass;
- Ruff passes;
- the Staff Product Manager skill passes the official skill quick validator;
- the seed suite resolves 20 cases across `en`, `pt-BR`, and `es`.

## Not yet satisfied

Behavioral scoring has not run. ProductOS does not yet define an approved model, judge prompt, repetition policy, cost budget, or human-calibration sample. Therefore this release is an alpha and makes no unsupported claim about score improvement over a baseline.

## Recommended next gate

Approve and run a reproducible behavior-eval protocol, then use observed failures to revise the skill before promoting `0.2.0` to stable. Research infrastructure work may proceed in parallel only where it does not assume unvalidated reasoning behavior.
