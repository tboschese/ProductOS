# Canonical knowledge

This directory will contain one YAML file per canonical entity, grouped by entity type.

Planned entity directories include:

```text
sources/
claims/
concepts/
frameworks/
terminology/
decision-patterns/
relationships/
cases/
anti-patterns/
```

Phase 0 intentionally contains no Product Management knowledge. Registries are populated only after the research infrastructure, review workflow, and cross-reference validators exist.
