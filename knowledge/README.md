# Canonical knowledge

This directory will contain one YAML file per canonical entity, grouped by entity type.

Planned entity directories include:

```text
sources/
claims/
concepts/
frameworks/
terminology/
decision-patterns/
relationships/
cases/
anti-patterns/
playbooks/
```

The initial decision-quality slice demonstrates the registry workflow. Its entities remain `in_review` until independent editorial verification. Broad registry expansion must proceed through bounded research tasks and the same provenance, review, eval, and regression gates.

`index.json` is generated by `python -m scripts.build_indexes --write` and must not be edited manually.
